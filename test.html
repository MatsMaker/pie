🍰 PIE Extension Test Page

This page contains a simple Pixi.js application. Use the PIE extension to edit the objects:

  • E + mouse - Scale object (hold Shift for uniform scaling)
  • W + mouse - Move object
  • Q + mouse - Rotate object
  • V - Toggle visibility
  • F - Select next item
  • D - Select previous item
  • Space - Log active item (Shift+Space for all items)

🔧 Pixi DevTools Integration: Select any object in Pixi DevTools (available as $pixi in console) and PIE will automatically switch to editing it!

Note: Make sure the PIE extension is loaded in Chrome!
